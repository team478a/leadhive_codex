LeadHive — Docker不要のWindows x64試作版

1. ZIPを右クリックして「すべて展開」。展開したフォルダ全体をローカルPCに置いてください。
2. LeadHive.exeをダブルクリック。
3. 初回管理者のメールアドレスと12文字以上のパスワードを入力し「初回セットアップ」。
4. 完了後「起動して画面を開く」。ブラウザで同じ情報を使ってログイン。
5. 終了時はランチャーの「停止」、またはランチャーを閉じます。

Docker、WSL、Python、Node、PostgreSQLの事前インストールは不要です。
初回セットアップ時もこれらをダウンロードしません。
データはWindowsユーザーのLocalAppData/LeadHiveNative/instance-v1へ保存します。
ZIPをUSBやGoogleドライブから運べます。ただし展開・実行はPCのローカルディスクで行います。

試作版の制限
・Windows x64専用。Windows 11で検証します。ARM・Macは対象外です。
・実送信OFF固定。バックグラウンドworkerは起動しません。
・既存Docker版とは別の新規データです。既存データを自動移行しません。
・自動更新・別PCへのデータ移行・バックアップ復元は未対応です。
・秘密情報はこのWindowsユーザー/PCに結び付けて暗号化します。
  保存フォルダをコピーするだけでは他PCへ移行できません。
・実行ファイルは未署名です。組織の実行制限やSmartScreenは別途確認が必要です。
・ランチャーを強制終了せず「停止」で終了してください。
・初回セットアップ失敗時に保存フォルダを削除しないでください。
  保存フォルダのruntime.log、postgres.logを管理者へ相談してください。
  ログには機密情報が含まれる可能性があるため公開投稿しないでください。
・PostgreSQLおよび同梱ライブラリのライセンスはpostgresqlフォルダに含まれます。

本試作版は環境依存を減らす方式の検証用です。本番配布版ではありません。
