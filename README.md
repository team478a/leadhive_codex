# LeadHive V2

LeadHive V2 は、業種ごとの営業先候補を収集し、企業情報を解析し、AIで営業適性を判定して優先順位付きリストを作成するBtoB営業リスト収集基盤です。

## 開発方針

- 開発主体: Codex
- 旧版: https://github.com/stockbusiness/leadhive
- 旧版は参照専用
- V2は新規設計
- 業種固有ロジックは Target Profile / Sales Objective で差し替える
- Phase単位で実装・検証する
