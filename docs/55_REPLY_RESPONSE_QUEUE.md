# 返信対応キュー 実装記録

## 目的

受信した営業返信を担当者が見落とさず、次の営業対応へ進めるようにする。

## 対象

プロジェクト内で、受信メールから返信として照合済みかつ営業状況が「返信あり」の企業を表示する。同一企業に複数の返信がある場合は最新の受信メールだけを表示する。不達通知・配信停止依頼・連絡禁止企業は対象外とする。

## 対応記録

返信内容と送信者を確認し、以下を記録できる。

- 返信確認・継続対応
- 商談化
- 失注
- 次回対応日時
- 対応メモ

記録後は営業状況と活動履歴を更新する。商談化または失注にした企業は返信対応キューから外れる。プロジェクトの閲覧・編集権限に従う。

## API

- `GET /api/projects/{project_id}/reply-queue`
- `POST /api/companies/{company_id}/reply-response`
