# 手動修正項目の再解析保護 実装記録

## 目的

企業情報を営業担当者が手動で修正した後、定期的なWeb再解析によって確認済みの値が意図せず上書きされることを防ぐ。

## 保護対象

企業詳細から次の項目を個別に保護・解除できる。

- 会社名、住所、都道府県、市区町村
- 電話、メール、問い合わせフォーム
- Instagram、X、TikTok、Facebook、YouTube、LINE

担当者はWeb解析の更新対象ではないため保護設定を設けない。サイト本文と事業概要はAI判定に新しい内容を渡すため、再解析時に常に更新する。

## 動作

- 企業情報の保存時に、値と項目ごとの保護状態を同時に保存する。
- Web解析は保護中の項目を変更しない。
- 保護されていない項目は解析結果に値がある場合に更新する。
- 保護を解除して再解析すると、最新の解析結果で更新する。
- リダイレクト後の公式URLとドメイン、解析状態、解析日時は保護対象外とする。

## DB変更

`companies.protected_fields`へ保護対象のフィールド名をJSON配列で保存する。既存企業はMigrationで空配列に補完し、補完後にDBの一時デフォルトを削除する。

## 検証

- 保護中の会社名・問い合わせURLが強制再解析後も維持されること
- 未保護の電話番号が再解析結果で更新されること
- 保護解除後に会社名・問い合わせURLが再解析結果で更新されること
- 不正なフィールド名をAPI入力検証で拒否すること
- デスクトップ・モバイルE2Eで保護設定を保存・再表示できること
