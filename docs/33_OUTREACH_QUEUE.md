# 営業アプローチキュー 実装記録

## 目的

収集・評価した企業を営業担当者が期限順に処理し、連絡実績、営業状況、次回対応を一度に記録できるようにする。

## 対象企業と優先順

営業対象、アプローチ済、返信あり、商談の企業のうち、メール、問い合わせフォーム、電話、SNSのいずれかで連絡可能な企業を表示する。連絡禁止企業と完了済み企業は除外する。

期限超過、期限設定済み、期限なしの順に並べ、同順位では期限とAIスコアを使用する。利用可能な経路は企業情報から判定し、メール、フォーム、電話、SNSの順で推奨する。

## 対応記録

キューから次をまとめて登録する。

- 実際に使った連絡経路
- アプローチ済、返信あり、商談、失注の結果
- 対応内容
- 次回対応日時

登録時は連絡経路に対応する活動履歴を追加し、営業状況が変わる場合は状況変更履歴も追加する。連絡禁止状態や、企業に存在しない連絡経路はAPIでも拒否する。

## API

- `GET /api/projects/{project_id}/outreach-queue`
- `POST /api/companies/{company_id}/outreach`

いずれも既存のプロジェクト所有権を検証する。キューは担当者、期限区分、件数で絞り込める。

## 検証

- 期限超過企業の優先表示
- 利用可能な連絡経路と推奨経路の判定
- 対応履歴、営業状況、次回対応日時の同時更新
- 連絡禁止企業と連絡先がない企業の除外
- 未登録経路による対応記録の拒否
- デスクトップ・モバイルのブラウザ操作
