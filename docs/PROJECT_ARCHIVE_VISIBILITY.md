# プロジェクト一覧の整理

基準: main@b610459c8560d9275ed617d72d0a768ff8ec4cf8

検証・終了した案件は既存の `Project.status = archived` を利用する。
DB・API・権限・送信境界の変更はない。プロジェクト名から自動分類はしない。

通常一覧では下書き・進行中を表示し、アーカイブは初期状態で隠す。
「アーカイブを表示」で件数・過去の案件・企業一覧を確認できる。
所有者は既存の編集画面でステータスを下書きまたは進行中に戻せる。
担当者の作業ガイドはアーカイブ以外のプロジェクトを扱う。
再読込時は通常表示へ戻る。表示切替でAPI更新・削除・収集・承認・送信を行わない。

2026-10-12、ユーザーの指示でクラウド内の検証用9件を既存の編集UIから
アーカイブへ変更した。企業・Raw・診断・Human判定・履歴は削除していない。
実営業用の新規案件作成・収集・送信は今回実行していない。
クラウドの表示変更は本PRのマージ・Web反映後に有効になる。

検証: frontend build（typecheck含む）、lint、既存の隔離Playwrightスイート。
新規ケースは通常表示／過去案件参照／再読込／全件アーカイブ／所有者による復帰を
Desktop・Mobileで確認する。外部API・実サイト・本番DBをテストから呼び出さない。
