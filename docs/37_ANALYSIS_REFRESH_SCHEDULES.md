# 企業情報の自動再解析 実装記録

## 目的

Web解析済みの企業情報が古いまま残らないよう、失敗企業と期限切れ企業を定期的に再解析する。

## 設定

プロジェクトごとに次を設定する。

- 実行間隔: 1〜720時間
- 期限切れ判定: 1〜3,650日
- 1回の最大件数: 1〜100社
- 有効・停止状態

設定はプロジェクトごとに1件とし、企業一覧のデータ品質欄から作成、変更、停止、再開、削除、即時実行できる。

## 対象選択

WebサイトURLがあり、次のいずれかに該当する企業を解析日時の古い順に選ぶ。

- Web解析に失敗
- 一度も解析されていない
- 最終解析が設定日数より古い

重複・公式サイト外として除外済みの企業は対象にしない。

## ワーカー動作

ワーカーは期限を迎えた設定からWeb解析ジョブを作成し、強制再解析として実行する。同一プロジェクトのWeb解析が待機中または実行中の場合は重複登録せず、見送り理由を設定へ記録する。対象がない場合は次回日時だけを更新する。

## API

- `GET /api/projects/{project_id}/analysis-refresh-schedule`
- `PUT /api/projects/{project_id}/analysis-refresh-schedule`
- `DELETE /api/projects/{project_id}/analysis-refresh-schedule`
- `POST /api/projects/{project_id}/analysis-refresh-schedule/run`

## 検証

- 設定の作成、更新、停止、削除
- 即時ジョブ登録
- 期限到来時の自動ジョブ登録
- 新しい解析結果と除外企業を対象外にする条件
- 実行中ジョブとの重複防止
- Migrationのdowngrade / upgradeとモデル差分検査
- デスクトップ・モバイルの設定操作
