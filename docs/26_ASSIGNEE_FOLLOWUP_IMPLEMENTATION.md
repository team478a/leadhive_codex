# 担当者・フォロー期限管理 実装記録

## 目的

営業対象企業の担当者を明確にし、次回対応期限を過ぎた企業を一覧とダッシュボードから把握できるようにする。

## 担当者

企業ごとに200文字以内の担当者名を保存する。組織・メンバー管理は現行スコープにないため、既存ユーザーID
への固定ではなく表示名として管理する。

- 企業詳細から編集
- 表示中の選択企業を最大100社まで一括更新
- 空欄指定による担当解除
- 担当者名の部分一致フィルター
- CSV出力
- 変更前後を活動履歴へ自動記録

## フォロー期限

既存の `next_followup_at` を使い、次の条件で企業一覧を絞り込む。

- 期限超過
- 本日
- 今後
- 未設定

「本日」は日本時間（Asia/Tokyo）の0時から翌日0時まで。期限超過と本日期限の件数をダッシュボードへ
表示する。日時自体は従来どおりタイムゾーン付きでDBへ保存する。

## API

`GET /api/projects/{project_id}/company-list` とCSV出力へ `assignee`、`followup` 条件を追加した。

`PATCH /api/projects/{project_id}/companies/bulk-assignee` は所有プロジェクト内の企業だけを更新し、指定IDが
1件でも見つからない場合は全体を404で拒否する。

## 検証

- 担当者の一括設定と活動履歴
- 担当者部分一致と期限超過の複合フィルター
- ダッシュボードの期限超過件数
- 既存企業を空担当者で補完するMigration往復
- バックエンド全テスト、Ruff、typecheck、lint、build、デスクトップ・モバイルE2E
