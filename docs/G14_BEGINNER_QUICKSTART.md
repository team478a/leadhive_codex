# LeadHive はじめての操作ガイド（収集・準備専用）

更新: 2026-10-03。初期提供では送信を停止しています。営業先の整理と文面準備から始めます。

## 1. 初回の準備

会社の管理担当者から受け取った**検証済みの配布ZIP**を使います。GitHubのソースZIPは使いません。会社ごとに専用のPC/VMが必要です。
ZIPを右クリックして「すべて展開」し、OneDriveなどの同期対象でない通常の場所へ保存します。ZIPの中で直接実行しません。

1. `Install-LeadHive.cmd`をダブルクリック。
2. Docker未導入なら、表示される公式要件・利用条件を管理者と確認し、画面に従います。
3. Windows再起動を求められたら再起動後、同じファイルをもう一度実行。
4. 初回管理者のメールと12文字以上のパスワードを入力。パスワードをチャットへ送らないでください。
5. ブラウザが開いたらログイン。上部に「外部送信は停止中」と表示されることを確認。

初回の取得・buildに時間がかかる場合があります。完了時のURLを使います。通常は`http://localhost:8787`ですが、別ポートが選ばれる場合もあります。
このURLはLeadHiveを入れたPCだけのURLです。スマートフォンに入力してもPC側の画面は開きません。

## 2. 最初はサンプル2件で練習

1. 「ターゲットプロファイル」で既存の対象条件を確認。
2. 「プロジェクト」の「プロジェクトを作成」を押す。名前を「受入練習」にし、プロファイル・営業目的・地域を選んで保存。
3. 「企業収集」で練習Projectを選び、CSV取込から`docs/acceptance/LEADHIVE_ACCEPTANCE_SAMPLE.csv`を選択。必要なら5列を同名へ割り当てます。
4. 「企業一覧」にサンプル1/2が表示されることを確認。もう一度同じCSVを取り込んでも同じ会社が増えないことを確認。
5. 「詳細」で担当・メモ・活動・次回対応日を入力し、再度開いて保存されたことを確認。

このCSVは架空データで、サイトURLを含みません。実企業への連絡・Web解析を行う練習ではありません。練習データは実案件と分けて管理します。

## 3. 文面と承認を練習

「承認キュー」で練習Projectを選び、架空宛先の「承認待ち提案を作成」を保存します。本文・送信者・宛先を確認し、再認証で承認できます。
承認しても送信されません。承認は内容確認の記録です。取消・却下も試せます。

APIキーが未設定ならAIによる文面生成や検索は実行できません。最初はCSV・手動の承認提案だけを使い、各社管理者が設定してから別途疎通を確認します。
実企業・実宛先を練習用に使わないでください。

## 4. 日常はこの5つ

| やりたいこと | 実行するファイル |
| --- | --- |
| 起動する | Start-LeadHive.cmd |
| 終了する（データは保持） | Stop-LeadHive.cmd |
| メール・フォーム送信を止める | Stop-LeadHiveOutbound.cmd |
| データを保存する | Backup-LeadHive.cmd |
| 保守後、収集・解析だけ再開する | Resume-LeadHive.cmd |

送信停止コマンドは一時的に画面を停止・再作成し、workerは停止したままになります。Resumeで環境IDの確認文字列を入力すると、送信停止を維持して収集・解析を再開します。
Backup後も同じようにResumeが必要です。古い送信待ちは保持されますが、初期モードでは送信されません。

## 5. バックアップとPC交換

Backup完了後、同名の`.dump`・`.dump.env.local`・`.dump.identity.json`を3点一組で、管理者が指定した安全な別媒体へ保管します。秘密を含むのでチャット・メールへそのまま添付しません。
`.env.local`やDockerのvolumeを削除しないでください。
PC交換は管理担当者と行います。元PCを停止し、新PCへ専用Importで移します。通常インストールや別会社のbackupで移行しません。
復元後は再ログイン・必要な提案の再承認が必要です。詳細は[導入・復元ガイド](73_WINDOWS_LOCAL_INSTALLER.md)。

## 6. 困ったとき

- 起動しない: Docker Desktop起動を確認。直らなければ`Diagnose-LeadHive.cmd`で診断を作成し、管理窓口へ連絡。
- 送信できない: 初期提供の正常動作です。SMTPテスト・フォーム・Codex引渡しも停止します。
- 定期収集が動かない: Backup/Update/Restore後にworkerが停止していないか確認し、案内されたResumeへ。
- 更新/復元が失敗: 画面を起動し直して回避せず、元データとファイルを保持して相談。
- 承認後の文面変更: 旧承認を使わず新しい提案を作成して再承認。

診断ファイルもPC名・ネットワーク情報を含み得るため、管理者が共有前に確認してください。初期提供では実メール・実フォーム送信や自動化を有効にしません。

詳しい機能は[利用マニュアル](82_LEADHIVE_USER_MANUAL.md)。
