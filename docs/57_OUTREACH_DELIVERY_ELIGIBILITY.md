# 送信完了ベースの成果帰属 実装記録

## 目的

送信予約、送信失敗、キャンセル済みの文面へ返信や商談を誤って帰属しないよう、成果分析の分母と帰属候補を実際の送信完了記録に限定する。

## 対象となる送信

- SMTPワーカーが送信成功として確定したメール
- LeadHiveが送信成功として記録した通常フォーム
- Codex支援で送信済みとして確認・記録したフォーム

メールを承認・予約しただけの状態、送信失敗、キャンセル済みの状態は対象にしない。承認履歴では、送信完了日時を表示し、未完了の場合は承認日時を表示する。

## 既存データ

更新時に、既存の送信成功メールと送信済みフォームの完了日時を送信承認履歴へ反映する。送信失敗やキャンセル済みのメールは成果分析の分母に含めない。
