# 営業活動成果分析 実装記録

## 目的

現在の営業ステータスだけでなく、指定期間内にどれだけアプローチし、返信・商談・成約へ進んだかを確認できるようにする。

## 集計

ログインユーザーが所有する全プロジェクトの営業状況変更履歴を対象に、次を集計する。

- 営業活動履歴の総数
- アプローチ済、返信あり、商談、成約へ変更した回数
- アプローチ数を分母にした返信率、商談率、成約率
- 現在の担当者別のアプローチ、返信、商談、成約件数

期間は1〜365日をAPIで指定でき、画面では7日、30日、90日、365日から選択する。期間中のアプローチが0件の場合、各成果率は0%とする。

担当者別集計は企業の現在の担当者を使用する。担当者変更時点のスナップショット分析は現行範囲に含めない。

## API

`GET /api/sales-activity-analytics?days=30`

ステータス変更時に既存の活動履歴へ記録される遷移情報を使うため、新たな入力操作は不要。

## 画面

ダッシュボードに次を追加した。

- 集計期間セレクト
- アプローチ数、返信率、商談率、成約率
- 担当者別の成果表

## 検証

- アプローチから成約までの連続した変更履歴を期間内に集計
- アプローチを分母にした各成果率
- 担当者別集計
- 集計期間の入力検証
- デスクトップ・モバイルE2Eで表示と期間切替を確認
