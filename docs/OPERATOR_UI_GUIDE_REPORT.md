# 担当者向けUI・ガイド整備

基準：main@21f89d78605284118c9564ad68473d2473e2cc3a。

- 常設の「担当者の作業ガイド」をメニューとプロジェクト画面に追加。
- 複数プロジェクトは明示選択。選択したプロジェクトを既存の企業収集・企業一覧へ引き継ぐ。
- 閲覧者は収集開始を無効化し、結果閲覧を可能にする。既存API権限は維持。
- 収集→問い合わせ先・営業NG確認→未送信入力→結果記録の4工程を表示。
- PCパッケージ、スマートフォンの役割、15分タスク、結果転送・手動取込の案内。
- 企業一覧と選択した企業の作業パネルを配信・追客・管理より前へ移動。既存機能を削除せず、候補確認へのスクロールを削減。
- 企業一覧に折りたたみの作業手順を追加。初回ガイドも日々の運用へ誘導。
- 管理者の準備と担当者の操作は OPERATOR_INPUT_WORKFLOW_GUIDE.md に記載。

DB・API・承認・送信・判定ロジック・feature flagは変更なし。
実企業のアクセス・入力・送信・クラウドへの配置は行わない。

検証：frontend typecheck / lint / build、モックAPIによるDesktop・MobileのUI検証。
モック試験は画面操作・対象プロジェクト引継ぎ・閲覧者・空データ・画面幅・書込なしを確認。
実運用の入力成功率、担当者の作業時間、クラウド配置後の動作は別途確認が必要。

実行結果：Desktop 3件 / Mobile 3件の6試験成功。CIにも同じ隔離試験を追加。DB・Backendは変更しておらず、全Backend・DB migration試験はローカル再実行対象外。buildの既存500kB超chunk警告は継続。
