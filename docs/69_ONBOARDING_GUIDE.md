# オンボーディングガイド実装

## 目的

初めて利用する担当者が、説明書を読まずに「プロジェクト作成 → 企業収集 → 企業確認」まで進められるようにする。

## 実装内容

- 初回ログイン後に3ステップのクイックスタートを自動表示
- 実際のプロジェクト数と企業数に応じて完了状態と次の操作を表示
- 最初はAPIキーなしでURL入力またはCSV取込を試せることを案内
- ガイドからプロジェクト作成、企業収集、企業一覧、運用設定へ直接移動
- サイドメニューの「使い方ガイド」からいつでも再表示
- プロジェクトがない画面にも作成ボタンとガイド表示ボタンを配置
- 閉じた状態を利用者単位でブラウザーに保存
- スマートフォンでは画面下から開くレイアウトを使用

## 検証

- `npm run typecheck`
- `npm run lint`
- `npm run build`
- ローカル環境で初回表示、サイドメニュー、デスクトップ表示を確認
- 390 × 844のスマートフォン表示で、本文と主要操作が横にはみ出さないことを確認
