# 都道府県の複数選択

基準: main `302d8db921b41dcba7b2197f88a292b36c94c605`。

ターゲット設定・プロジェクト編集の地域欄、およびGoogle検索の収集条件で「都道府県を複数選択」を押すと、チェック式で複数の県を指定できる。スマートフォンでは2列のスクロール可能な一覧で選ぶ。単一地域と市区町村の選択、自由入力は残す。

- 全国と個別県は排他的。最後の県を解除すると全国へ戻ることを画面に明示する。
- 複数選択では市区町村指定を解除し、各都道府県全体を対象とする。
- 保存形式は既存の `大阪府 / 兵庫県`。DB・APIの新規フィールドやmigrationは不要。
- 新しく作成するSerperの `prefecture_order` 計画では、各県×キーワードを独立したクエリにする。県の順序は既存の北海道→沖縄県の順序で固定し、重複県は一度だけ扱う。
- 新規計画のsnapshotに `selected_prefectures` を含め、計画hashに反映する。既存の固定済みsnapshotには追加しないため、再開する既存ジョブの検索内容は変えない。
- 市区町村や自由入力の文字列、literalモード、Google Places・gBizINFOの検索ロジックは変更しない。これらの収集画面は従来の単一選択を維持する。
- 収集目標と検索回数上限は全地域で共有。県を増やしても予算を県ごとに増やさない。設定保存だけで検索は開始しない。

外部検索、実企業アクセス、承認、送信、本番データ変更は検証に含めない。検証は専用test DBとAPI mockのデスクトップ・モバイルPlaywrightで行う。本番反映にはマージ後のWebとAPI／収集workerの更新が必要。
