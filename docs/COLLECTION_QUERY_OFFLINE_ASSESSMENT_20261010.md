# 検索語改善のオフライン評価（2026-10-10）

## 結論

次の比較は、ページ数や検索予算を増やす前に、**検索語をサービス提供ページ寄りに変える効果**を測る。今回は保存済み20件だけを再評価し、新しい検索・企業サイトGET・AI・DB更新・承認・送信は実行していない。公式サイト候補はHuman Truthではなく、適合率の実測値はnull。

求人ドメインの除外は保存データ上では有望。ただし、検索語変更と除外条件を同時に変えると原因を分離できないため、最初のライブ比較では検索語だけを変更する。除外語の本体実装は行っていない。

## 原因と改善案

| 原因 | 確認した事実 | 対応候補 |
|---|---|---|
| 検索意図が広い | keyword + regionは会社、比較記事、求人を区別しない | サービス提供意図を指定した検索語と比較 |
| 比較記事が多い | ARTICLE 8件 | 現在のURL・タイトル単位の除外を維持。企業ドメイン全体をブラックリスト化しない |
| 求人が多い | JOB_PR 5件、いずれも求人媒体 | 求人媒体のdomain限定除外を次の独立した比較候補にする |
| 類義語追加は重複も増やす | 過去の大阪「SNS運用支援 会社」は10件中8件が既出 | Found数でなく、新規有効候補の増分を評価 |

`-求人 -採用 -おすすめ -比較`を一括で追加する方針は採らない。公式サービスページにも採用案内や比較説明があり得る。保存タイトルに対する自由語除外は、検索エンジンの演算子挙動を再現しない。合成の公式サービスURL＋採用タイトルがdomain限定除外では保持されることだけを確認した。
