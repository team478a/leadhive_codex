# 承認付きフォーム送信 実装記録

## 目的

問い合わせフォーム用に作成・確認した営業文面を、利用者の明示承認後に1社ずつ送信できるようにする。

## 操作

企業詳細のフォーム文面で「フォーム項目を確認」を選ぶと、対象サイトからPOST形式フォームの入力項目を読み込む。利用者は項目と本文を確認・入力し、承認チェックと確認ダイアログを経て送信する。

送信リクエストが受理されると、フォーム送信履歴と企業の活動履歴を残す。企業が未確認または営業対象なら、営業状況をアプローチ済へ更新する。

## 対応範囲

- 同一サイト内へPOSTする通常HTMLフォーム
- テキスト、メール、電話、本文、選択肢の入力項目
- hiddenのCSRFトークンなど、フォームページに含まれる非表示項目

CAPTCHA、選択式チェックボックス・ラジオ、パスワード、ファイル添付、外部サイトへ送信するフォームは自動送信しない。これらは手動送信へ切り替える。

対応外フォームは、後続の`47_CODEX_ASSISTED_FORM_DELIVERY.md`にあるCodex支援送信へ引き渡す。

## 安全条件

- 連絡禁止企業には送信しない
- フォーム文面だけを対象にする
- 明示承認がなければ外部サイトへPOSTしない
- 同じ文面は一度だけフォーム送信できる
- robots.txtで取得が許可されないサイトは自動送信しない

## API

- `GET /api/outreach-drafts/{draft_id}/form-preview`
- `POST /api/outreach-drafts/{draft_id}/form-delivery`

## 検証

- 項目プレビュー、明示承認、外部送信モック
- 活動履歴と営業状況更新
- 同一文面の重複送信拒否
- Migrationのupgrade / downgrade、全自動テスト、PC・スマートフォンE2E、build
