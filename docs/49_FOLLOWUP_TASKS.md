# 追客タスク 実装記録

## 目的

期限を設定した次回対応を担当者の作業一覧として表示し、対応後に完了または延期できるようにする。

## 対象

営業対象、アプローチ済、返信あり、商談の企業で、次回対応日時が設定され、連絡禁止ではない企業を表示する。期限超過を先頭にし、その後は期限の早い順に並べる。

## 操作

- **完了**: 次回対応日時を解除し、対応メモを活動履歴へ残す
- **延期**: 現在より後の次回対応日時を指定し、変更前後の期限と対応メモを活動履歴へ残す

完了済み、失注、対象外、連絡禁止の企業はAPIでも処理できない。対応メモは必須で、単なる期限変更ではなく対応内容を確認できる。

## API

- `GET /api/projects/{project_id}/followup-tasks`
- `POST /api/companies/{company_id}/followup-task`

取得APIは担当者、期限区分、件数で絞り込める。処理APIは`completed`または`rescheduled`、対応メモ、延期時の次回対応日時を受け取る。
