# 検索テンプレート・定期収集 実装記録

## 目的

繰り返し使う検索条件をプロジェクトへ保存し、指定間隔で検索収集を自動登録する。収集件数が増え続ける
ことを防ぐため、プロジェクト内の企業保存上限もテンプレートごとに設定する。

## 機能

- Serper / Google Places、キーワード、地域、キーワードごとの最大件数をテンプレート化
- 1〜720時間の実行間隔
- プロジェクト内企業数の上限（1〜100,000社）
- 有効化、停止、削除、今すぐ実行
- 次回実行日時、前回登録日時、実行見送り理由の表示
- ワーカーによる期限到来テンプレートの自動ジョブ登録

新規テンプレートの初回自動実行は、作成時刻から設定間隔が経過した時点。保存直後に実行する場合は
「今すぐ実行」を使用する。

## 重複実行と上限

同じプロジェクトに検索収集の待機中・実行中ジョブがある場合、その回の定期実行は見送り、次回日時を
更新する。企業数が保存上限以上の場合も見送り理由を記録する。

上限未満で処理を開始した場合、各キーワードの実行前に残り保存可能数を再計算し、外部サービスへ
要求する最大件数を残数までに制限する。既存のURL・会社情報による重複判定も引き続き適用する。

## API

| Method | Path | 内容 |
| --- | --- | --- |
| GET / POST | `/api/projects/{project_id}/search-schedules` | 一覧 / 作成 |
| PUT / DELETE | `/api/search-schedules/{schedule_id}` | 全項目更新 / 削除 |
| POST | `/api/search-schedules/{schedule_id}/run` | 今すぐジョブ登録 |

全APIでプロジェクト所有権を確認する。Placesの最大件数は60、キーワードは20件まで。

## 検証

- 作成、一覧、更新、停止、削除、即時実行
- 期限到来時の自動登録
- 実行中ジョブがある場合の見送り
- 企業保存上限による見送り
- バックエンド全テスト、Migration往復、Ruff、typecheck、lint、build
- デスクトップ・モバイルE2E
