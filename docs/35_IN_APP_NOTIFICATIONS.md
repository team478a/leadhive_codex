# アプリ内通知センター 実装記録

## 目的

フォロー期限超過やバックグラウンド処理失敗を、利用者がダッシュボードで見落とさず確認できるようにする。

## 通知対象

- 営業対象、アプローチ済、返信あり、商談の企業で次回対応期限を過ぎたもの
- 未確認のまま残っている失敗バックグラウンド処理

連絡禁止企業、成約・失注・対象外など完了済み企業はフォロー期限通知から除外する。

通知一覧取得時に対象を同期する。同じ企業と期限、または同じ処理ジョブから通知を重複作成しない。企業の次回対応期限が変更され、再度期限を超過した場合は新しい通知として扱う。

## 既読管理

通知ごとの既読化と一括既読に対応する。通知はユーザーへ直接紐付け、別ユーザーからの既読操作は404として扱う。サイドバーのダッシュボードには未読件数を表示する。

## API

- `GET /api/notifications`
- `POST /api/notifications/{notification_id}/read`
- `POST /api/notifications/read-all`

一覧は未読のみの指定と最大取得件数に対応する。

## 検証

- 期限超過と処理失敗の通知生成
- 同一対象の重複通知防止
- 個別既読と一括既読
- ユーザー間のアクセス分離
- Migrationのdowngrade / upgradeとモデル差分検査
- デスクトップ・モバイルの通知確認操作
