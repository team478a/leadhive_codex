# LeadHive V2 - Vision and Scope

## 1. 開発目的

LeadHive V2 は、BtoB営業に必要な営業先候補を収集し、企業情報を解析し、営業対象としての適性をAIで判定し、優先順位付き営業リストを作成するシステムとする。

V1の中心目的は次の1点。

> ターゲット条件を設定すると、営業候補企業を収集し、AIが営業対象としての適性を分析し、優先順位付きリストを作成できる。

## 2. 想定利用例

- SNS運用事業者へのワタシワークスOEM営業
- トラック・運送事業者向け営業
- Web制作会社向け営業
- 広告代理店向け営業
- 建設会社向け営業
- 採用会社向け営業
- その他BtoB営業

## 3. 重要な設計方針

SNS会社専用、運送会社専用のシステムにはしない。

業種ごとの違いは以下で吸収する。

- Target Profile
- Sales Objective
- Search Keywords
- Positive Conditions
- Negative Conditions
- Exclusion Conditions
- Scoring Rules
- AI Instruction

## 4. V1のゴール

V1では以下まで完成すればよい。

1. プロジェクト作成
2. ターゲットプロファイル選択
3. 営業目的入力
4. 検索条件設定
5. 企業収集
6. Web解析
7. 重複排除
8. AI営業適性判定
9. A / B / C / 対象外分類
10. 営業リスト確認
11. CSV出力

## 6. V1完成条件

異なる2業種で実運用できること。

### ケース1
SNS運用会社を100社収集
→ Web解析
→ AI判定
→ A/B/C/対象外
→ ワタシワークスOEM営業リスト完成

### ケース2
トラック・運送会社を100社収集
→ Web解析
→ 案件目的に応じたAI判定
→ A/B/C/対象外
→ 営業リスト完成

この2ケースが成立すれば、V1の汎用性検証完了とする。
