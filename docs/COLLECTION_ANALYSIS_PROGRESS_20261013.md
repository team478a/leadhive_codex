# 収集済み企業の解析操作表示

## 問題と変更
- 一括解析のボタンはAPIへの登録中だけ状態を表示しており、ジョブが待機中・実行中でも通常表示に戻っていた。
- 現在のプロジェクトのWeb解析・AI判定ジョブを見て、待機/実行の間はボタンを反転（白背景・緑文字・緑枠）、状態を明記し、重複クリックを防ぐ。
- 完了・失敗・キャンセル後は通常のボタン表示と対象有無の判定へ戻る。既存2秒ポーリングで自動反映。
- 更新ボタンのPromiseエラーは画面に出ていなかった。更新専用の受付状態を設け、収集の受付状態とは分ける。処理中は更新中…、成功/失敗を通知し、失敗後も再試行可能。

## 範囲
Frontendのみ。解析内容・バックエンドのジョブ状態・承認条件・送信機能を変更しない。実企業へのアクセス、AI利用、収集・送信を今回のテストでは行わない。

## 検証
PlaywrightモックでWeb解析/AI判定の待機→実行→完了、反転色、重複POST防止、更新エラー→再試行をPCとスマートフォンで確認する。既存の収集受付・通知テストも実行。Frontend typecheck/lint/buildとAPI importを確認。実環境で待機が長く続く原因は、本変更だけでは判定できない。

## 結果
- `npm run typecheck` / `npm run lint` / `npm run build`: 成功。
- `npx playwright test --config operator-guide.config.ts operator-tests/action-feedback.spec.ts`: 6件成功（PC3件・スマートフォン3件）。
- `python -c "import app.main"`: 成功。
- 本番データ変更・実サイト解析・AI利用・デプロイは行っていない。
