# 連絡禁止・連絡先品質管理 実装記録

## 目的

連絡拒否、既存顧客、競合などへ誤って再アプローチすることを防ぎ、連絡先がどこから取得され、いつ確認されたかを管理する。

## 連絡禁止

- 企業詳細から理由付きで連絡禁止を設定・解除する。
- 設定時に営業状況を対象外へ変更する。
- 連絡禁止中はアプローチ済など他の営業状況へ変更できない。
- ドメイン、メール、電話をプロジェクト単位の抑止リストへ保存する。
- 元企業を削除しても抑止リストは残り、URL・CSV・検索による再収集を保存前に除外する。
- 解除時は一致する抑止情報を削除する。
- 設定と解除を活動履歴へ記録する。

## 連絡先品質

次の状態を企業単位で保持する。

- 未確認
- Web取得済み
- 人手確認済み
- 無効

Web解析で電話、メール、問い合わせフォームのいずれかを取得した場合は「Web取得済み」とし、取得元URLと確認日時を記録する。営業担当者は企業詳細から人手確認済み・無効へ変更できる。

## API

`PATCH /api/companies/{id}/contact-control`

所有プロジェクト内の企業だけを更新できる。連絡禁止を設定する場合、除外理由は必須。

## 検証

- 理由なしの連絡禁止を拒否
- 連絡禁止時の営業状況変更を拒否
- 企業削除後も同一ドメインの再収集を抑止
- Web解析時の品質状態、取得元、確認日時
- Migrationのdowngrade / upgradeとAlembic差分検査
- デスクトップ・モバイルで設定・解除操作
