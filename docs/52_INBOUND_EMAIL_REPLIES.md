# 受信メール返信取込 実装記録

## 目的

営業メールへの返信をIMAP受信箱から取り込み、企業の営業状況と活動履歴へ反映する。

## 設定と実行

管理画面の「メール設定」でIMAPホスト、ポート、受信ユーザー名、メールボックス、SSL、確認間隔を保存する。パスワードは既存のSMTP設定と同じ暗号化キーで暗号化して保存し、画面へ再表示しない。

有効化後、バックグラウンドワーカーが指定間隔ごとに未読メールを確認する。「接続をテスト」と「今すぐ確認」も管理画面から実行できる。ワーカーは従来どおり `python -m app.worker` で起動する。

## 照合と反映

送信者メールアドレスが企業のメールアドレス、または先方担当者のメールアドレスに**一意に一致**した場合だけ企業へ紐付ける。複数企業に一致するものや一致しないものは未照合として記録し、自動で営業状況を変更しない。

未確認、営業対象、アプローチ済の企業は「返信あり」へ更新し、受信メールと営業状況変更を活動履歴へ残す。返信あり、商談、成約、失注、対象外の企業は既存の営業状況を変更しない。

本文は先頭4KBから抽出した最大1,000文字の要約だけを保存する。メール本文の完全な保管は本実装の対象外とする。未照合メールの手動紐付けは `53_INBOUND_EMAIL_MANUAL_MATCHING.md` を参照する。

## API

- `GET /api/admin/inbound-mail-settings`
- `PUT /api/admin/inbound-mail-settings`
- `POST /api/admin/inbound-mail-settings/test`
- `POST /api/admin/inbound-mail-settings/sync`
- `GET /api/admin/inbound-emails?limit=20`

すべて管理者専用。設定・受信一覧ともに受信メールの内容を扱うため、一般メンバーには公開しない。
