# 承認付きメール送信 実装記録

## 目的

営業文面を人が確認した後に限り、登録済みの企業または先方担当者へメールを送信または予約送信できるようにする。

## 操作

メール文面の件名・本文を確認し、送信先と送信日時を選択して承認する。承認時点の件名・本文を送信内容として固定し、ワーカーがSMTP経由で送信する。

送信日時を空欄にすると次回のワーカー処理で送信する。待機中はキャンセルでき、失敗時は内容を再確認してから再送できる。送信成功時は企業の活動履歴へ宛先と件名を記録する。

## 安全条件

- 送信対象はメール文面だけ
- 送信先は企業または無効ではない先方担当者に登録済みのメールアドレスだけ
- 利用者の明示承認がなければ送信予約を作成しない
- 同じ下書きは1件だけ送信予約または送信できる
- 連絡禁止企業は予約・再送できない
- 送信中にワーカーが停止した場合は自動再送せず、失敗として人の再確認を求める
- 閲覧者は送信履歴を参照できるが、予約・キャンセル・再送はできない

## SMTP設定

`.env`にSMTPホスト、ポート、送信元メールアドレス、必要に応じて認証情報を設定する。パスワードはGit管理しない。設定がない場合、送信は失敗として記録され、メールは送信されない。

## API

- `GET /api/outreach-drafts/{draft_id}/email-delivery`
- `POST /api/outreach-drafts/{draft_id}/email-delivery`
- `POST /api/email-deliveries/{delivery_id}/cancel`
- `POST /api/email-deliveries/{delivery_id}/retry`

## 検証

- 明示承認、登録済み宛先、連絡禁止の検証
- 承認時点の件名・本文を固定して送信すること
- 送信成功時の活動履歴記録
- 送信失敗、再送、キャンセル
- 閲覧者の参照と更新拒否
- Migrationのdowngrade / upgradeとモデル差分検査
