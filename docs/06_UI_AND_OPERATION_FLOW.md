# LeadHive V2 - UI and Operation Flow

## 1. 必要画面

1. ログイン
2. ダッシュボード
3. プロジェクト一覧
4. プロジェクト作成
5. 企業収集
6. 企業一覧
7. 企業詳細
8. ターゲットプロファイル管理
9. 設定

## 2. プロジェクト作成画面

入力:
- プロジェクト名
- Target Profile
- Sales Objective
- Region
- Status

## 3. 企業収集画面

入力:
- Source
- Search Keywords
- Region
- Max Results

例:

ターゲット: SNS運用事業者
地域: 全国
キーワード:
- SNS運用代行
- Instagram運用代行
- TikTok運用代行
件数: 100

[収集開始]

## 4. 収集結果

表示例:

- 100社収集
- Aランク: 18社
- Bランク: 34社
- Cランク: 29社
- 対象外: 19社

## 5. 企業一覧

表示:
- rank
- score
- company_name
- business_type
- region
- website
- phone
- email
- contact
- SNS
- AI summary
- status

Filter:
- rank
- score
- region
- status
- source
- keyword

Sort:
- score desc
- newest
- company_name

- Aランク
- Bランク
- Cランク
- 対象外
- 営業対象

- 返信あり
- 商談
