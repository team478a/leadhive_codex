# 追客通知からの直接操作 実装記録

## 目的

ダッシュボードに届いた本日予定・期限超過の追客通知から、対象企業の追客タスクを直接開き、完了または延期まで進められるようにする。

## 操作

通知ごとに「追客を開く」を表示する。選択すると未読通知を既読にし、対象プロジェクトの企業一覧へ移動する。該当企業の追客タスクを開いた状態で表示し、スマートフォンでは入力欄まで自動スクロールする。

すでに完了・延期・対象外・連絡禁止になった企業は追客タスクに含まれないため、その場合は追客画面を開かない。通知自体は既読にできる。

## 権限

通知は既存どおり対象プロジェクトを参照できる利用者だけに表示される。追客タスクの完了・延期は既存APIの編集権限と状態検証に従う。

## 検証

- 本日予定と期限超過の通知から対象企業IDとプロジェクトIDを引き渡す
- 通知を開いた時だけ未読を既読にする
- 返信通知の返信対応導線を維持する
- フロントエンドの lint と本番ビルドを実施する
