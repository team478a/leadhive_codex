# 営業施策別成果分析 実装記録

## 目的

承認済みのメール・フォーム送信について、送信方法と件名ごとに営業の進展を比較できるようにする。

## 集計

指定期間に送信完了したメール、LeadHive通常フォーム、Codex支援フォームを件名ごとに集計する。送信済み件数に対して、その送信へ記録された返信・商談・成約件数と返信率を表示する。

受信返信は、受信日時より前に同一企業で送信完了した送信のうち、最も新しいものへ紐付ける。送信予約中、失敗、キャンセルのメールは対象にしない。返信対応で商談化または成約を記録した場合も、選択した受信返信と同じ送信へ成果を記録する。同じ送信に複数の返信があっても、施策分析では送信ごとに一件として数える。

この記録は新規に取り込む返信と対応から作成される。既存の営業状況だけから過去の成果を推定して集計することはしない。

## API

`GET /api/outreach-effectiveness-analytics?days=30`

期間は1〜365日を指定でき、ログインユーザーが参照できるプロジェクトだけを対象にする。
