# 営業施策別成果分析 実装記録

## 目的

承認済みのメール・フォーム送信について、送信方法と件名ごとに営業の進展を比較できるようにする。

## 集計

指定期間に承認された送信を、メール、LeadHive通常フォーム、Codex支援フォームと件名で集計する。承認件数に対して、対象企業の現在の営業状況が返信あり・商談・成約へ進んでいる件数と返信率を表示する。

同じ企業への複数承認は、それぞれの承認操作として集計する。営業状況は現在値を使うため、送信と成果の厳密な因果関係を示すものではなく、施策を比較するための運用指標である。

## API

`GET /api/outreach-effectiveness-analytics?days=30`

期間は1〜365日を指定でき、ログインユーザーが参照できるプロジェクトだけを対象にする。
