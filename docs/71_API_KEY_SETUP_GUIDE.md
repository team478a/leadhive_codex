# APIキー取得ガイド

## 目的

管理者が別の説明書を探さずに、運用設定画面から外部サービスの利用開始手順を確認できるようにする。

## 対応サービス

- Serper API：Google検索による企業収集
- Google Places API（New）：店舗・事業所検索
- OpenAI API：AI判定と営業文面生成
- gBizINFO API：国内法人情報の収集

## 画面の内容

- サービスごとの用途
- アカウント作成からAPIキー取得までの手順
- LeadHiveで入力する設定欄
- 課金・利用申請・キー制限に関する注意
- 公式サイト・公式ドキュメントへのリンク
- 「設定済み」「未設定」の状態表示

Serperの手順を最初から展開し、他のサービスは必要なときだけ開く構成にした。APIキーは取得手順へ入力せず、運用設定のパスワード欄へ直接入力する。

## 注意事項

- Google Places API（New）はGoogle Cloudプロジェクト、請求先、有効化、APIキー制限を設定する。
- OpenAI APIの利用料はChatGPT契約とは別にAPI Platformで管理する。
- gBizINFOは動作確認用トークンではなく、Web API利用申請で発行されたトークンを使用する。
- APIキーをGitHub、チャット、メールへ貼り付けない。
