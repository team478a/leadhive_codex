# 受信メール手動紐付け 実装記録

## 目的

自動照合できなかった受信メールを、管理者が正しい企業へ紐付けられるようにする。

## 操作

メール設定画面の未照合メールで、企業名・ドメイン・メールアドレスを検索し、候補から企業を選択して紐付ける。自動照合済みのメールは変更できない。

紐付けると受信メールの記録を企業へ関連付け、活動履歴に手動紐付け操作を残す。企業の営業状況が未確認、営業対象、アプローチ済の場合だけ返信ありへ更新する。返信あり以降の状態は維持する。

## API

- `GET /api/admin/inbound-email-companies?query=...`
- `POST /api/admin/inbound-emails/{inbound_email_id}/match`

受信メールの内容を扱うため、どちらも管理者専用とする。
