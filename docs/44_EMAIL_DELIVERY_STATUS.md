# メール配信状況一覧 実装記録

## 目的

送信予約、送信成功、失敗、キャンセルの状況を企業詳細へ一件ずつ開かずに確認できるようにする。送信量制御によって待機中のメールも、プロジェクト全体の件数と履歴から把握できるようにする。

## 画面

サイドバーの「メール配信状況」で、アクセス可能なプロジェクトを選択できる。以下を表示する。

- 送信待ち、送信中、送信済み、失敗、キャンセル済みの件数
- 企業名、宛先、件名
- 予約日時と送信日時
- 送信失敗時の公開可能な理由

メール設定の上限・間隔により待機するメールは、送信待ちとして表示される。再送やキャンセルは、誤送信を防ぐ既存の明示承認フローを維持するため企業詳細から行う。

## API

- `GET /api/projects/{project_id}/email-deliveries?limit=100`

プロジェクトの所有者・編集者・閲覧者は一覧を取得できる。権限のないプロジェクトは404として扱う。返却上限は200件。

## 検証

- 送信待ちと送信済みの集計、企業名を含む一覧
- 既存の送信・失敗・再送権限テスト
- 全自動テスト、PC・スマートフォンE2E、Ruff、typecheck、lint、build
