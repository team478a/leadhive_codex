# フォーム確認削減 Q3：項目名ルール

## 目的

フォーム確認キューで繰り返し現れる未解決の必須項目を、プロジェクト単位の項目名ルールとして一度だけ決め、同じ正規化項目名・型のフォームへまとめて反映する。

この機能は保存済み解析の対応先を決めるだけで、対象サイトへのアクセス、AI呼び出し、送信、承認、承認依頼の作成は行わない。送信可否の再集計と既存の送信前確認は従来どおり実行する。

## 画面での使い方

1. 「送信の準備・実行」からフォーム確認キューを開く。
2. 「項目名ごとに決める」タブを選ぶ。
3. 未解決の項目名、型、フォーム数、表記例を確認する。
4. 対応先を選び、「このルールを保存して○フォームに反映」を押す。
5. 確認ダイアログに表示される会社名・フォームURLの例（最大5件）を確認する。
6. バックグラウンド処理の件数と進捗を確認する。

保存済みルールは同じタブで確認できる。「無効にする」は将来の適用を止めるだけで、反映済み項目を維持する。反映済み項目も取り消す場合は「このルールで決めた項目を未決定に戻す」を使う。

## 保存と適用

- `form_label_rules` に、プロジェクト、正規化項目名、型、対応先、選択値、状態、作成者、作成・無効日時を保存する。
- 同じプロジェクト・正規化項目名・型の有効ルールは1件だけに制限する。
- 反映元を追跡するため、`form_profile_fields.label_rule_id` にルールIDを保存する。
- 保存時の一括反映は `OperationJob(operation_type='form_label_rule')` で100フォームずつ処理する。
- 解析・再解析時にも有効ルールを適用するが、辞書で確定できなかった必須項目だけを対象にする。
- 反映した項目は `decision_source='RULE'`、`confidence=1.0` とし、`FormAnalysisLog.field_mapped` に `label_rule_id` を記録する。
- 反映後は共通のフォーム状態再計算を実行し、実行待ち・実行中の処理がなければ送信可否の再集計を1件だけ登録する。

## 誤反映の防止

- `MANUAL` と `POLICY` の決定を上書きしない。
- 辞書で `mapped_key` と十分な確信度が決まった項目を上書きしない。
- `privacy_consent`、`newsletter_consent`、`unknown` は項目名ルールの対応先にできない。
- 1フォーム内で同じ対応先が重複する場合は、そのフォームに適用しない。
- `message` は `textarea` だけ、`email` は `email` または `text` だけに設定できる。
- `select`／`radio` の既定値は任意。保存された値が対象フォームの選択肢に存在しない場合、そのフォームには適用しない。
- `contact_method` の対応先は設定できるが、送信値は既存の人手確認を通す。
- 無効化後も反映済み項目は保持する。取り消しはそのルールIDが記録された `RULE` 項目だけを未決定に戻す。

## API

- `GET /api/projects/{project_id}/form-label-rules`
- `GET /api/projects/{project_id}/form-label-rules/preview`
- `POST /api/projects/{project_id}/form-label-rules`
- `POST /api/projects/{project_id}/form-label-rules/{rule_id}/retire`
- `POST /api/projects/{project_id}/form-label-rules/{rule_id}/reset`

閲覧はプロジェクト閲覧権限、保存・無効化・取り消しは編集権限を必要とする。

## 検証

- 同一項目名・型への反映、状態再計算、監査ログ、送信可否再集計を専用PostgreSQLで確認した。
- 手動・ポリシー・辞書結果の保護、同一フォームの重複、型制約、選択肢不一致を確認した。
- 解析・再解析で未解決項目だけに再適用されることを匿名HTMLで確認した。
- 無効化で反映済み項目が残り、取り消しで当該ルール由来の項目だけが戻ることを確認した。
- プロジェクト分離、有効ルールの一意性、Migrationのupgrade／downgrade／再適用、モデル差分なしを確認した。
- 対象サイトへのアクセス、実送信、承認、承認依頼、外部AIは実行していない。

## 未解決事項と次の条件
