# プロジェクトメンバーと権限 実装記録

## 目的

一人の所有者だけでなく、複数ユーザーで営業プロジェクトを参照・運用できるようにする。

## 権限

- 所有者: プロジェクト編集・削除、メンバー管理を含むすべての操作
- 編集者: 企業収集、解析、AI判定、営業状況・担当者・活動履歴などの運用操作
- 閲覧者: プロジェクト、企業一覧・詳細、収集・処理履歴、分析結果の参照

閲覧者による更新系APIは404として扱い、プロジェクトの存在自体を権限外ユーザーへ開示しない。編集者もプロジェクト設定の変更、削除、メンバー管理は行えない。

## メンバー管理

所有者はプロジェクト一覧から、登録済みユーザーのメールアドレスを指定して編集者または閲覧者として追加する。同じユーザーを再登録した場合は権限を更新する。所有者自身の追加は拒否する。

## API

- `GET /api/projects/{project_id}/members`
- `POST /api/projects/{project_id}/members`
- `DELETE /api/projects/{project_id}/members/{member_id}`

プロジェクト一覧とダッシュボード集計は共有されたプロジェクトも含む。期限超過・処理失敗通知も共有メンバーごとに生成する。

## 検証

- 所有者による追加、権限変更、削除
- 閲覧者による一覧・詳細参照
- 閲覧者による更新拒否
- 編集者による営業状況更新
- メンバーによるメンバー管理の拒否
- 削除後のアクセス失効
- Migrationのdowngrade / upgradeとモデル差分検査
- デスクトップ・モバイルのメンバー管理操作
