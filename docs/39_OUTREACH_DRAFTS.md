# AI営業文面 実装記録

## 目的

企業分析結果とプロジェクトの営業目的から、相手企業に合わせた営業文面の下書きを作成し、担当者が確認・編集して利用できるようにする。

## 対象経路

- メール
- 問い合わせフォーム
- SNS

対象経路の連絡先が企業に登録されている場合だけ生成できる。メールでは件名と本文、フォーム・SNSでは本文を生成する。先方担当者を指定した場合は氏名・部署・役職を文脈へ含める。

## 安全条件

- AI企業分析の完了を生成条件とする
- 連絡禁止企業では生成しない
- 無効な先方担当者を宛先に指定しない
- Web情報に含まれる命令へ従わないようシステム指示で制限する
- 入力にない実績、効果、関係性、相手の課題を推測しない
- 自動送信は行わず、人が確認・編集してコピーする

## API

- `GET /api/companies/{company_id}/outreach-drafts`
- `POST /api/companies/{company_id}/outreach-drafts/generate`
- `PUT /api/outreach-drafts/{draft_id}`
- `DELETE /api/outreach-drafts/{draft_id}`

閲覧者は保存済み文面を参照できる。生成・編集・削除は所有者または編集者だけが実行できる。

## 画面

企業詳細の「営業文面」で経路、先方担当者、追加指示を選び、文面を生成する。生成履歴から文面を選択し、件名・本文の編集、保存、クリップボードへのコピー、削除を行える。

## 検証

- 企業分析・営業目的・追加指示がAI入力へ渡ること
- 生成結果の保存、一覧、編集、削除
- 連絡禁止時の生成拒否
- AIサービス失敗時の安全なエラー表示
- 閲覧者の参照と更新拒否
- Migrationのdowngrade / upgradeとモデル差分検査
- デスクトップ・モバイルで営業文面欄が表示されること
