# 都道府県・市区町村選択

## 目的

プロジェクト作成時の対象地域を、自由記述だけでなく都道府県と市区町村から簡単に指定できるようにする。

## 実装内容

- 全国または47都道府県を選択可能
- 都道府県の選択後、該当する市区町村を選択可能
- 都道府県全体を対象にする指定に対応
- 複数都道府県や独自の地域名は自由入力へ切り替えて指定可能
- 市区町村候補を取得できない場合は市区町村の手入力へ自動切替
- 保存形式は既存の `region` 文字列を維持し、DB Migrationを不要にした

## 市区町村データ

市区町村候補には、国土交通省位置参照情報と日本郵便のデータをもとに毎月更新されている
[Geolonia 住所データ](https://geolonia.github.io/japanese-addresses/)の都道府県・市区町村APIを利用する。

## 保存例

- 全国: `全国`
- 都道府県全体: `東京都`
- 市区町村指定: `東京都 / 渋谷区`
- 複数地域: `大阪府 / 兵庫県`
